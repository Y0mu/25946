# объединённые задачи 2 и 3: доступ к файлу и время в калифорнии

Программа показывает real UID и effective UID, проверяет возможность открытия `data.txt`, вызывает `setuid(getuid())` и повторяет проверку. При каждом успешном открытии файла выводится текущая дата и время в часовом поясе `America/Los_Angeles` (PST зимой и PDT летом).

Важно: программа **проверяет** доступ к файлу, но не выдаёт новые права. `setuid(getuid())` не является выдачей разрешений. Если запускать программу от обычного пользователя, UID обычно не изменится.

## запуск

Откройте терминал в папке `task_2_3`:

```sh
make
./access_time
```

Для повторной сборки:

```sh
make clean
make
./access_time
```

## что увидим

```text
=== before setuid ===
real_uid=...
effective_uid=...
file_access=granted (data.txt)
california_time=... PDT

=== after setuid ===
real_uid=...
effective_uid=...
file_access=granted (data.txt)
california_time=... PDT
```

Вместо `PDT` зимой будет `PST`, числа даты и UID зависят от машины.

## файлы

- `access_time.c` - объединённый исходный код задач 2 и 3
- `Makefile` - сборка программы
- `data.txt` - тестовый файл, который открывает программа

## mac и сервер нгу

На Mac запускайте в Terminal после распаковки. На сервере НГУ (Illumos/SunOS) распакуйте архив, перейдите в папку `task_2_3` и выполните те же команды. Для проверки не нужны права администратора.
